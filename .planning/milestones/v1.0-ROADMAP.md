## Overview

This refactor milestone narrows a sprawled research workspace down to two pillars — the TransArc empirical study and the benchmark bias analysis — then verifies both pillars reproduce cleanly, and finally restructures the LaTeX paper to match. Work flows in one direction: reorganize first, verify second, write paper third. Nothing moves back upstream.

## Phases

- [x] **Phase 1: Reorganize** - Move scripts/reports into the two-pillar structure and archive out-of-scope work
- [x] **Phase 2: Verify** - Confirm both pillars run end-to-end and all imports/paths are intact after the moves
- [x] **Phase 3: Paper** - Restructure eval.tex to match the two-pillar structure (Ch1=TransArc, Ch2=Bias)

## Phase Details

### Phase 1: Reorganize
**Goal**: The workspace is structured as two explicit pillars with out-of-scope work moved to archive
**Requirements**: SCOPE-01..05, ARCH-01..04
**Success Criteria**:
  1. `src/` has a clear Pillar 1 grouping (transarc) and Pillar 2 grouping (bias)
  2. `s12c_sadcode_comparison.py` + `reports/S12C_VS_TRANSARC.csv` co-located with Pillar 1
  3. `src/annotation/` gone; both annotation scripts under `archive/`

**Outcome**: ✓ Complete — `src/transarc/` (4 scripts), `src/bias/` (9), `src/lib/` unchanged; annotation work archived; all via `git mv`, zero code edits.

### Phase 2: Verify
**Goal**: Both retained pillars run reproducibly — every script executes and regenerates its report with paths intact
**Requirements**: REPRO-01, REPRO-02, REPRO-03
**Success Criteria**:
  1. Every Pillar 1 script runs clean and writes its report
  2. Every Pillar 2 script runs clean and writes its report
  3. Shared `src/lib/` importable by both pillars (no broken `sys.path`)
**Outcome**: ✓ Complete — 13/13 scripts exit 0; reports regenerate byte-identically.

### Phase 3: Paper
**Goal**: `writing/eval.tex` restructured as Ch1=TransArc study, Ch2=Benchmark bias; every claim traces to a retained artifact
**Requirements**: PAPER-01, PAPER-02, PAPER-03, PAPER-04
**Success Criteria**:
  1. Ch1 covers the TransArc empirical study (SAD-SAM bottleneck, amplification, cascade, s12c)
  2. Ch2 covers benchmark bias (two prior chapters merged into one)
  3. Every figure/table/claim traces to a retained script or report
  4. (reframed) Tables generated from data via script + structural validation; `pdflatex` out of scope (no toolchain; chapters feed a larger external paper)
**Outcome**: ✓ Complete — eval.tex Ch1 `\input{ch1_transarc}` + merged Ch2; `src/paper/generate_tables.py` emits 10 booktabs tables; structural validation passes.
