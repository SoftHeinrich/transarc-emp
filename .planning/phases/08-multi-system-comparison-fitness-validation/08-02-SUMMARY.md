### Task 2 — Hardened COMPONENT_SUITE.md + graceful-skip demonstration

Edited `reports/COMPONENT_SUITE.md` (only file changed by this plan):

- **swattr ≡ transarc one column (D-12):** added an explicit systems-description note
  (SWATTR ⋈ ArCoTL at doc-to-code; live contrast = heuristic-uniform SWATTR vs
  LLM-peaky-but-leaky artemis). The existing Caveats note was tagged with D-12.
- **Skip-with-notice policy (D-08):** added a dedicated section that (a) tables the three
  guarded roots `AGENT_LINKER`, `ARTEMIS_DOC_CODE`, `ARTEMIS_LOCAL` with what each feeds
  and its status, (b) quotes the **exact** `_warn_skip` message format
  (`WARNING: no <level> result links for system=<label> project=<project> (absent or empty external root); skipping`),

  08-02 demonstration result inline.
- **Provenance cross-reference:** links `reports/ARTEMIS_PROVENANCE.md` (08-01) as the

- **No stale numbers:** every cited AVG/per-project figure in the two result tables and
  the Findings was re-checked against the regenerated CSVs and matches (e.g. swattr/transarc
  sad-code AVG micro 0.795 / macro 0.813 == CSV `AVG,swattr/transarc,0.7949,0.8134`;
